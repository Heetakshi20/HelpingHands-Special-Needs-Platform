Spelling Patterns
  • 👉 Silent e: hop → hope (vowel becomes long)
  • 👉 Double consonants: run → running (short vowel)
  • 👉 i before e: believe, receive (except after c)
  • 👉 Change y to i: cry → cries, baby → babies
Silent e
hop → hope tap → tape cut → cute cap → cape
Double Consonants
run → running swim → swimming hop → hopping sit → sitting
Change y to i
cry → cries baby → babies fly → flies try → tries
hop + ing = ?
Hint: For short vowel sounds, double the consonant before adding -ing.
