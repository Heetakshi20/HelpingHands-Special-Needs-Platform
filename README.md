# HelpingHands | Personalized Virtual Reality Learning for Special Students

**HelpingHands** is a full-stack educational platform designed to provide tailored support for neurodiverse students, specifically those with **Autism**, **Down Syndrome**, and **Dyslexia**. The platform connects students with specialized mentors through an adaptive interface and an **AI-driven video call system** that facilitates real-time engagement and emotional support.

## 🚀 Key Features

*   **Adaptive Dashboards**: Personalized UI/UX based on the student's specific learning requirements (Autism, Down Syndrome, or Dyslexia).
*   **AI Video Mentoring**: Real-time AI interaction using **Web Speech API** for Speech-to-Text (STT) and Text-to-Speech (TTS).
*   **Secure Booking System**: Students can book sessions with specialized mentors (like Ms. Nisha Sharma for Down Syndrome).
*   **Progress Tracking**: A rewarding system where mentors award **Star Ratings** and notes after each session.
*   **Admin Oversight**: A central hub to manage registrations, monitor contact inbox, and track student exam scores.

## 🛠️ Tech Stack

*   **Frontend**: HTML5, CSS3, JavaScript (Vanilla)
*   **Backend**: Node.js, Express.js
*   **Database**: MongoDB (MERN Stack)
*   **Authentication**: JSON Web Tokens (JWT) & Bcryptjs
*   **AI/Real-Time**: Web Speech API & Jitsi Meet WebRTC
